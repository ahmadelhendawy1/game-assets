# AI4EduTech Game Assets

Art, sound and a small loader for the games teachers make with the **AI4EduTech HTML Player**.
The games are generated by AI from the HTML Player prompts. They load everything from here through the free jsDelivr CDN.

## Use in a game (Phaser 3.80)

```html
<script src="https://cdn.jsdelivr.net/npm/phaser@3.80.1/dist/phaser.min.js"></script>
<script src="https://cdn.jsdelivr.net/gh/ahmadelhendawy1/game-assets@9b418bf8ccd6459151a91845514a2c003be7408c/ai4-assets.js"></script>
```

```js
preload() { AI4Assets.preload(this, { pack: 'runner-desert' }); }
create() {
  AI4Assets.parallax(this);                                  // sky + hills that scroll with the camera
  AI4Assets.ground(this, 0, 620, 4000, 100);                 // repeating grass ground
  const hero = AI4Assets.hero(this, 150, 620, { height: 150 });  // feet at (x, y)
  hero.setPose('run');   // idle | run | jump | fall | hurt | celebrate
  hero.face(-1);         // 1 = right, -1 = left
  hero.flashHurt();
  this.add.image(900, 620, AI4Assets.key('door')).setOrigin(0.5, 1);
  const tag = AI4Assets.label(this, doorSprite, 'is walking');   // HTML label that follows an object (Arabic-safe)
  tag.setHighlight(true);
  AI4Assets.sfx(this, 'correct');
  AI4Assets.music(this, 'adventure');
  AI4Assets.setMuted(this, true);
  // top-down games: endless scrolling background
  const sea = AI4Assets.scroller(this, 'sea-tile', { speed: 120 }); sea.speed = 0;
}
```

Always use a **version tag** (`@v1.0.0`), never `@main`. A tag never changes, so games teachers already made keep working when new art is added.

## What's inside

| Folder | Contents |
|---|---|
| `ai4-assets.js` | The loader: packs, cut-out hero animation, parallax, ground, HTML labels, sound, drawn fallbacks |
| `packs/sea`, `space`, `maze`, `soccer`, `castle`, `kart` | One pack per game (images + `pack.json` with names and sizes). See `demo/gallery.html` to browse them all |
| `packs/runner-rides/` | Horse with rider and kart with driver for Runner Quest: `AI4Assets.ride(scene, x, feetY, { type: 'horse' or 'kart' })` |
| `packs/runner-desert/` | Runner Quest, desert world. Image keys: `door`, `door-open`, `coin`, `flag`, `crystal`, `heart`, `platform`, `crate`, `spikes`, `ground`, `enemy`, `boss`, `bg-far`, `bg-mid`, `hero-full`, plus the 6 hero parts |
| `audio/sfx/` | 20 effects (.ogg + .mp3): `tap select commit jump land coin correct wrong hurt boss-hit power-up level-up victory tick go whoosh splash door-open shoot kick-ball` |
| `audio/music/` | 8 seamless loops: `adventure sea space mystery stadium castle race boss` |
| `demo/` | A playable level using everything, also a test page |
| `source/` | The original ChatGPT images, kept so packs can be re-exported |
| `tools/` | `synth_sounds.py` (makes every sound from code), `build_loader.py` (copies every `packs/*/pack.json` into the loader; run it after adding a pack) and `art/` (slices sheets, rigs the hero, exports WebP) |
| `ART-PROMPTS.md` | ChatGPT prompts for every game's art |

The sounds share one brand signature: a rising 3-note bell motif (G–C–E) heard in `correct`, `power-up`, `level-up`, `victory` and inside every music loop.

## Fallbacks

If an image can't load, the loader draws a coloured placeholder with the same name and size. If a sound can't load, it stays silent. Games never crash because of a missing asset.
